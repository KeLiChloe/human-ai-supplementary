LLM prompt for analyzing the diagrams

Survey respondents wrote causal diagrams in text form (arrows and effect signs). An LLM coded each response into three structure metrics: number of paths, maximum path length, and number of latent variables. Empty, missing, or ill-defined diagrams were coded as -1.
